# Projekt-The-fascination-of-Rain-P5.js
„The Fascination of Rain“ ist eine interaktive Ganzkörperinstallation, bei der Bewegungen der Besuchenden eine digitale Regenszene beeinflussen. Im Gruppenprojekt verantwortete ich die technische Konzeption und Programmierung der Körpererkennung mit PoseNet und ml5.js sowie der Interaktionslogik mit p5.js und p5play.js.
